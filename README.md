# Wordle for Android

A clone of Wordle for Android, in **Kotlin**.

## Features

- **Sound effects**
- **Game history**: results of previous games saved in a local database.
- **Voice input**.
- **Bluetooth multiplayer**: play against another player over Bluetooth. The player who guesses their word in less rounds is the winner. In case of a draw, the player who first guesses their word wins.

## Tech Stack

- Kotlin
- Android SDK
- Local database
- Android SpeechRecognizer
- Android Bluetooth API

## Permissions

To enable all functionalities, the app needs the following permissions:

- Microphone (voice input)
- Bluetooth (multiplayer mode)
- Location (multiplayer mode)
